Bench · USB · node · network

Plug it in, and watch each sensor breathe.

Connect a DIY node by USB to see every sensor on it working, live, and whether it is reaching WiFi and its broker. Several boards at once is fine. Opened from a PLANETAI node, the same page also shows every device that node reads on your network. Once opened, it works without internet.

Nothing connected yet

Plug the board in with a data cable and press Connect. Pick the port that says USB JTAG/serial or usbmodem. No board at hand? The demo plays two Bayu sensors and a node, clearly marked as demo.

A browser cannot scan a network. This map is what the node knows: every sensor that publishes to it, every radio its gateway hears, the platforms and stations it reads, the nodes it lists. And the boards on this computer's USB.

A PLANETAI node

The node answers this page when the page comes from the node itself (its address, then /tester), or from this machine. A token lets it show everything at SHARE_LEVEL=off; planetai ui prints it.
