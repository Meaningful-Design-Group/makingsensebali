Flash · Making Sense Bali

A USB cable, this page, and the board is yours.

Put the firmware on a DIY air node or a Meshtastic radio from the browser. Nothing to install: the page talks to the board over USB. Chrome or Edge on a laptop; phones, Safari and Firefox cannot open a serial port.

01 · The sensor

The DIY node, one image for every board.

Firmware v5 runs on the Seeed XIAO ESP32-S3 and the ESP32-C3 SuperMini, and finds whichever sensors are plugged in at boot: HM3301, Sensirion SEN5x, BME680. The page detects the chip, so there is one button.

DIY node · v5

Flash the node

Plug the board in with a data cable (a charge-only cable shows nothing). If no port appears, hold BOOT while plugging in. Then press the button, pick the port, and let it run: about a minute.

This browser cannot open a USB port. Use Chrome or Edge on a laptop, on this page's https address. Phones, Safari and Firefox do not support Web Serial.
The v5 image has not been built yet. The build runs from GitHub when the firmware changes; until then flash from the Arduino IDE as the build guide describes.
Reflashing keeps the node's saved WiFi, token and name. A node that has never been set up opens its portal on first boot.

Then, once

  1. On your phone, join the WiFi network MSB-Node-xxxx, password makingsense. The setup page opens; if not, browse to 192.168.4.1.
  2. Give the node your WiFi, a name, the site, the mounting height, and tick indoors if it hangs in a room.
  3. Where it publishes. Leave the broker blank for Smart Citizen (then paste the device token from your device page). To send readings to a PLANETAI node in the house instead, type what planetai broker prints on that machine:
Broker host
the node machine's .local name or LAN address
Port
1883
User
planetai
Password
printed by planetai broker
Token
the Smart Citizen token, or any six characters if the node is the only reader
Only the token ever reaches Smart Citizen. Name, site and height stay local, on the node's own status page.
02 · The radio

Meshtastic, the release every radio shares.

One firmware version across a mesh, always: radios on different versions stop hearing each other in ways nothing reports. This page carries the stable release the PLANETAI nodes run. The XIAO flashes from here; the Seeed trackers take a file copied to a drive.

ESP32-S3 · gateway or sensor node

XIAO ESP32-S3 + Wio-SX1262

One image whatever the job: Meshtastic firmware is per board, the job is settings. As the gateway it uses its WiFi, the mesh's door to the node. As a sensor node (the Bayu sensor by Fab Lab Bali) it carries an I2C sensor and sits where the reading is wanted; it has no GPS, so the node gives it a fixed position when it is provisioned. The flasher erases it fully and installs the release; the radio comes up with no region and no channel, which is correct, those come next.

This browser cannot open a USB port. Use Chrome or Edge on a laptop, on this page's https address. Phones, Safari and Firefox do not support Web Serial.
Antenna on before power, always. Never use the phone app's over-the-air update on this board: Seeed says it can brick it.
nRF52840 · field sensor

Wio Tracker L1 / L1 Lite

No WiFi, GPS, a Grove port for a 3.3 V sensor, a battery. Double-click RST: a drive appears. Copy the file onto it; the radio reboots on its own.

Region and channel come from the node, not from here

A radio with no region never transmits, and nothing tells you. A radio on the wrong frequency slot is outside what Indonesia allows. So this page sets neither: the node operator's QR carries the region, the frequency slot and the mesh's channel keys together, and importing it sets all three at once.

  1. Open the Meshtastic app, connect to the radio over Bluetooth (PIN 123456 on radios without a screen).
  2. Scan the QR the node operator shows you, from planetai radio url on the node. Accept replacing the channels. That is region, slot and keys, done.
  3. Or skip the phone: plug the radio into the node and run planetai radio provision sensor "Subak edge" SBK --port …, with --fixed LAT,LON for a XIAO, which has no GPS. Same result, and the node remembers the radio.
Bali runs SG_923 with the slot pinned inside 920–923 MHz. Menorca EU_868, Boston US. Whoever runs the node has already made that choice; a radio only needs to copy it.

Why the page cannot flash the trackers

The nRF52 boards do not take firmware over a serial port; they show up as a USB drive and take a file. That is a copy, not a flash, and no browser button can do it for you. The ESP32 boards do take firmware over serial, which is what the two buttons above use.

All files on this page are the ones in the Meshtastic release, unchanged. Their checksums are in SHA256SUMS next to them; the release's own manifest is kept alongside.
